Draw in the air
with a Joy-Con.

Wand turns a Switch 2 Joy-Con into a wand for your Windows PC. Hold ZR, draw a shape, let go. A circle takes a screenshot, a flick skips the track, a Z undoes. Lay it on the desk and it is a mouse.

Fourteen shapes to start with

Each one can be rebound, switched off, or drawn again in your own hand. To add a new one, draw it three times and say what it should do. Pick a row to watch it drawn.

    Set it down and it is a mouse

    A Joy-Con 2 has an optical sensor in its rail. Lay the controller on its side with the rail down and it moves the cursor. Lift it and the same buttons are the wand's again, so you can draw an infinity to bring up your open windows, then set it down and click the one you want.

    On a left Joy-Con the two buttons are L and ZL. So far it has only been tried on a desk. A rougher surface, such as cloth, may need a looser limit, which is one line in the settings file.

    What it is made of

    Link
    Bluetooth LE, using the Joy-Con 2's own pairing. No dongle, and nothing to pair in Windows.
    Motion
    Gyro, accelerometer and magnetometer, fused into one orientation about 68 times a second.
    Mouse
    The optical sensor in the rail. The controller counts as set down when the sensor sees a surface close by and the rail faces the floor, so a hand wrapped around it does not move the cursor. Each report's movement is spread over the next 15 ms, so the cursor moves on every frame of a fast display.
    Overlay
    A click-through window on every monitor, drawn at the display's refresh rate: 240 fps on a 240 Hz panel. Nothing is on screen until you hold the trigger. The trail on this page is the same renderer, running in your browser.
    Matching
    Template matching tuned on a few hundred strokes from a real hand. An oval still counts as a circle, and a tick still counts as a V.
    Actions
    Key combinations, media keys, programs and shell commands. The action runs the moment you let go; the animation follows.
    Settings
    One commented text file holds every threshold. Save it and the running app reloads it.

    Set it up

    1. Run the installer

      It is not code-signed, so Windows SmartScreen will stop it. Choose More info, then Run anyway.

    2. Hold the sync button

      The small round one on the Joy-Con's rail, until the lights chase. Do not pair it in Windows settings; Wand does the pairing.

    3. Hold ZR and draw

      The trail follows your hand on whichever monitor you point at.

    You need a Switch 2 Joy-Con, Windows 11 and Bluetooth.

    Tested with one right-hand Joy-Con 2. The left one and the Pro Controller 2 are handled in the code and have not been tried. A Joy-Con paired with Wand stops reconnecting to the console until you pair it there again.
